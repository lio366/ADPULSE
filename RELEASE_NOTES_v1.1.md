# Release notes — ADPULSE v1.1.2

## Changed
- Product language policy is now English and Spanish only.
- Regional browser locales normalize to `en` or `es`; unsupported locales fall back to English.
- Arabic RTL and all additional locale metadata/catalog entries have been removed.
- Localization documentation now describes the actual two-language scope and incomplete surface coverage.

## Validation
- Focused localization suite: 7/7 tests passed.
- Full application typecheck/build and end-to-end tests remain unverified.
